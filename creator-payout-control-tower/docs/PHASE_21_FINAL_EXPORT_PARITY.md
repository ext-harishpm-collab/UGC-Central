# Phase 21 - Frozen Author Level export and parity report\n\nA frozen payout batch can be exported into the internal Final Author Level CSV. It retains author identity, PAN/TDS fields when sourced, bank verification, Book/Show lineage, contractual RS when uniquely resolved, calculation components, QC status, batch ID and source references.\n\nThe export endpoint refuses non-frozen batches. The parity endpoint compares eligible earning gross against recorded Finance payment net for the period and returns the delta for review; it does not auto-correct mismatches.\n
